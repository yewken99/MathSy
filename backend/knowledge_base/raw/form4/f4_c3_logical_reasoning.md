# Topic: Logical Reasoning / Mathematical Reasoning
**Form:** Form 4 | **Chapter:** Chapter 3 | **Curriculum:** SPM KSSM

## Overview
Logical reasoning is used to determine whether mathematical statements are true or false and to form valid conclusions from given information. In this topic, students learn about statements, negation, compound statements, implications, converse, inverse, contrapositive, counter-examples, and arguments.

## Concept: Statement
A statement is a sentence whose truth value can be determined. The truth value must be either true or false, but not both.

**Key Rules / Methods:**
- A statement can be true or false.
- Questions, exclamations, and commands are not statements because their truth values cannot be determined.
- Mathematical statements are not always true.
- A sentence with an unknown variable may not be a statement if its truth value depends on the value of the variable.

### Worked Example:
Determine whether each sentence is a statement or not a statement.

(a) Please send the workbook.

This is not a statement because its truth value cannot be determined.

(b) Kuala Lumpur Tower is the tallest tower in Malaysia.

This is a statement because its truth value can be determined.

(c) How do you come to school?

This is not a statement because it is a question.

(d) $x + 3 = 5$

This is not a statement because its truth value depends on the value of $x$.

(e) $-6 < -8$

This is a statement because it is false.

### Common Mistakes & Exam Tips:
- A false sentence can still be a statement.
- A command is not a statement.
- A question is not a statement.
- A sentence with a variable is not always a statement unless enough information is given.

## Concept: Truth Value of Mathematical Statements
The truth value of a mathematical statement is whether the statement is true or false.

**Key Rules / Methods:**
- A true statement is a statement that is correct.
- A false statement is a statement that is incorrect.
- If a statement is false, give a reason or counter-example.
- Statements using words such as “all” and “some” must be checked carefully.

### Worked Example:
Determine whether each statement is true or false. If false, explain.

(a) $(x + y)^2 = x^2 + 2xy - y^2$, where $x \neq 0$ and $y \neq 0$.

False.

Let $x = 2$ and $y = 3$.

$$
(x + y)^2 = (2 + 3)^2 = 25
$$

$$
x^2 + 2xy - y^2 = 2^2 + 2(2)(3) - 3^2
$$

$$
= 4 + 12 - 9
$$

$$
= 7
$$

Since $25 \neq 7$, the statement is false.

(b) $(x + 5)^2 < 0$, where $x \in \mathbb{R}$.

False.

For example, when $x = 2$:

$$
(2 + 5)^2 = 49
$$

Since $49 > 0$, the statement is false.

(c) $2 + 6(4) > 4 + 6(2)$.

$$
2 + 6(4) = 2 + 24 = 26
$$

$$
4 + 6(2) = 4 + 12 = 16
$$

Since $26 > 16$, the statement is true.

(d) $2 \in \{\text{Factors of } 8\}$.

True because $2$ is a factor of $8$.

### Common Mistakes & Exam Tips:
- “All” means every case must be true.
- “Some” means at least one case is true.
- To prove a statement with “all” is false, one counter-example is enough.
- Do not assume a mathematical statement is true just because it looks formal.

## Concept: Quantifiers “All” and “Some”
Quantifiers are words that show how many cases are being referred to.

**Key Rules / Methods:**
- “All” means every object in the group satisfies the condition.
- “Some” means at least one object in the group satisfies the condition.
- A statement with “all” is false if there is at least one counter-example.
- A statement with “some” is true if at least one suitable example exists.

### Worked Example:
Determine whether each statement is true or false.

(a) All polygons have diagonals.

False. A triangle is a polygon but it has no diagonal.

(b) Some perfect squares are whole numbers.

This wording is true because there are perfect squares that are whole numbers, such as $4$ and $9$.

(c) All even numbers have prime factors.

True.

(d) Some straight lines intersect the $y$-axis.

True.

### Common Mistakes & Exam Tips:
- “Some” does not mean “all”.
- If only one example satisfies the condition, a “some” statement is true.
- If one example fails, an “all” statement is false.

## Concept: Negation of a Statement
Negation changes the truth value of a statement. The negation of statement $p$ is written as $\sim p$.

**Key Rules / Methods:**
- Use “no” or “not” to negate a statement.
- The negation of $p$ is written as $\sim p$.
- If $p$ is true, then $\sim p$ is false.
- If $p$ is false, then $\sim p$ is true.
- “All” is usually negated as “not all”.
- “Is” is usually negated as “is not”.

### Worked Example:
Form a negation for each statement.

(a) $12$ is a multiple of $5$.

Negation:

$12$ is not a multiple of $5$.

(b) $41$ is a prime number.

Negation:

$41$ is not a prime number.

(c) All multiples of $5$ are multiples of $10$.

Negation:

Not all multiples of $5$ are multiples of $10$.

(d) $0.4$ m is equal to $400$ mm.

Negation:

$0.4$ m is not equal to $400$ mm.

### Common Mistakes & Exam Tips:
- Do not simply add “not” in a grammatically confusing way.
- The negation of “all” is “not all”, not always “none”.
- The negation must have the opposite truth value of the original statement.

## Concept: Compound Statement
A compound statement is a combination of two or more statements using the word “and” or “or”.

**Key Rules / Methods:**
- “And” means both statements must be true.
- “Or” means at least one statement must be true.
- A compound statement using “and” is true only when both parts are true.
- A compound statement using “or” is false only when both parts are false.

### Truth Table:
| $p$ | $q$ | $p$ and $q$ | $p$ or $q$ |
|---|---|---|---|
| True | True | True | True |
| True | False | False | True |
| False | True | False | True |
| False | False | False | False |

### Worked Example:
Combine the statements using “and” and “or”.

$p$: A pentagon has two diagonals.

$q$: A heptagon has four diagonals.

Using “and”:

A pentagon has two diagonals and a heptagon has four diagonals.

Using “or”:

A pentagon has two diagonals or a heptagon has four diagonals.

### Worked Example:
Determine the truth value of the compound statement:

$$
x + 3 < x - 5
$$

and $99$ is an odd number.

Statement $p$:

$$
x + 3 < x - 5
$$

This is false because subtracting $x$ from both sides gives:

$$
3 < -5
$$

which is false.

Statement $q$:

$99$ is an odd number.

This is true.

Since $p$ is false and $q$ is true:

$$
p \text{ and } q = \text{False}
$$

Therefore, the compound statement is false.

### Worked Example:
Determine the truth value of the compound statement:

The sum of interior angles of a triangle or a quadrilateral is $360^\circ$.

Statement $p$:

The sum of interior angles of a triangle is $360^\circ$.

False, because the sum is $180^\circ$.

Statement $q$:

The sum of interior angles of a quadrilateral is $360^\circ$.

True.

Since $p$ is false and $q$ is true:

$$
p \text{ or } q = \text{True}
$$

Therefore, the compound statement is true.

### Common Mistakes & Exam Tips:
- For “and”, one false part makes the whole compound statement false.
- For “or”, one true part makes the whole compound statement true.
- In Mathematics, “or” usually means one or both.

## Concept: Implication “If $p$, then $q$”
An implication is a statement in the form “If $p$, then $q$”.

**Key Rules / Methods:**
- In “If $p$, then $q$”:
  - $p$ is the antecedent.
  - $q$ is the consequent.
- The antecedent is the condition.
- The consequent is the result.

### Worked Example:
Determine the antecedent and consequent.

If $x$ is a factor of $16$, then $x$ is a factor of $64$.

Antecedent:

$x$ is a factor of $16$.

Consequent:

$x$ is a factor of $64$.

### Worked Example:
Form an implication “if $p$, then $q$”.

Antecedent: $k$ is divisible by $5$.

Consequent: $k$ is a multiple of $5$.

Implication:

If $k$ is divisible by $5$, then $k$ is a multiple of $5$.

### Common Mistakes & Exam Tips:
- The part after “if” is the antecedent.
- The part after “then” is the consequent.
- Do not reverse the antecedent and consequent unless the question asks for the converse.

## Concept: Implication “$p$ if and only if $q$”
An implication in the form “$p$ if and only if $q$” means both directions are true.

**Key Rules / Methods:**
The statement “$p$ if and only if $q$” consists of two implications:
- If $p$, then $q$.
- If $q$, then $p$.

### Worked Example:
Write two implications based on:

$$
\sqrt{r} = 15
$$

if and only if:

$$
r = 225
$$

Implication 1:

If $\sqrt{r} = 15$, then $r = 225$.

Implication 2:

If $r = 225$, then $\sqrt{r} = 15$.

### Worked Example:
Form an implication “$p$ if and only if $q$”.

If $k$ is a prime number, then $k$ has only two factors.

If $k$ has only two factors, then $k$ is a prime number.

Combined implication:

$k$ is a prime number if and only if $k$ has only two factors.

### Common Mistakes & Exam Tips:
- “If and only if” means both directions must be considered.
- Do not treat “if and only if” as only one implication.
- When asked to write two implications, write both directions clearly.

## Concept: Converse, Inverse, and Contrapositive
For an implication “If $p$, then $q$”, the converse, inverse, and contrapositive are related forms.

**Key Rules / Methods:**
| Type | Form |
|---|---|
| Statement | If $p$, then $q$ |
| Converse | If $q$, then $p$ |
| Inverse | If $\sim p$, then $\sim q$ |
| Contrapositive | If $\sim q$, then $\sim p$ |

### Worked Example:
Write the converse, inverse, and contrapositive of:

If $x$ is a positive number, then $x$ is greater than $0$.

Statement:

If $x$ is a positive number, then $x$ is greater than $0$.

Converse:

If $x$ is greater than $0$, then $x$ is a positive number.

Inverse:

If $x$ is not a positive number, then $x$ is not greater than $0$.

Contrapositive:

If $x$ is not greater than $0$, then $x$ is not a positive number.

### Worked Example:
Write the converse, inverse, and contrapositive of:

If $x = 5$, then $x + 1 = 6$.

Converse:

If $x + 1 = 6$, then $x = 5$.

Inverse:

If $x \neq 5$, then $x + 1 \neq 6$.

Contrapositive:

If $x + 1 \neq 6$, then $x \neq 5$.

### Common Mistakes & Exam Tips:
- Converse reverses $p$ and $q$.
- Inverse negates both $p$ and $q$ without reversing them.
- Contrapositive reverses and negates both parts.
- The contrapositive has the same truth value as the original implication.
- The converse and inverse have the same truth value as each other.

## Concept: Truth Value of an Implication
The truth value of an implication depends on the truth values of its antecedent and consequent.

**Key Rules / Methods:**
- “If $p$, then $q$” is false only when $p$ is true and $q$ is false.
- If the antecedent $p$ is false, then the implication is always true.
- The contrapositive has the same truth value as the implication.
- The converse and inverse have the same truth value as each other.

### Truth Table:
| $p$ | $q$ | If $p$, then $q$ | Converse | Inverse | Contrapositive |
|---|---|---|---|---|---|
| True | True | True | True | True | True |
| True | False | False | True | True | False |
| False | True | True | False | False | True |
| False | False | True | True | True | True |

### Worked Example:
Determine the truth values of the statement, converse, inverse, and contrapositive.

Statement:

If $2 \times 3 = 6$, then $8 - 2 \times 3 = 18$.

Antecedent:

$$
2 \times 3 = 6
$$

This is true.

Consequent:

$$
8 - 2 \times 3 = 18
$$

Using order of operations:

$$
8 - 6 = 2
$$

So the consequent is false.

Since the antecedent is true and the consequent is false, the implication is false.

Converse:

If $8 - 2 \times 3 = 18$, then $2 \times 3 = 6$.

The antecedent is false and the consequent is true, so the converse is true.

Inverse:

If $2 \times 3 \neq 6$, then $8 - 2 \times 3 \neq 18$.

The antecedent is false and the consequent is true, so the inverse is true.

Contrapositive:

If $8 - 2 \times 3 \neq 18$, then $2 \times 3 \neq 6$.

The antecedent is true and the consequent is false, so the contrapositive is false.

### Common Mistakes & Exam Tips:
- An implication is not automatically false when the antecedent is false.
- The only false case is: true antecedent, false consequent.
- Always determine the truth value of $p$ and $q$ first.

## Concept: Counter-Example
A counter-example is an example used to show that a statement is false.

**Key Rules / Methods:**
- For a false statement, at least one counter-example can be given.
- A counter-example must directly contradict the statement.
- Counter-examples are commonly used for statements involving “all”.

### Worked Example:
Determine the truth value. If false, give one counter-example.

(a) The sum of interior angles of all polygons is $180^\circ$.

False.

A pentagon is a polygon, and the sum of its interior angles is $540^\circ$.

Therefore, a pentagon is a counter-example.

(b) Some prime numbers are even numbers.

True.

The number $2$ is an even prime number.

(c) $4$ and $8$ are factors of $20$.

False.

$4$ is a factor of $20$, but $8$ is not a factor of $20$.

(d) $6$ or $36$ is a multiple of $9$.

True.

$36$ is a multiple of $9$.

### Common Mistakes & Exam Tips:
- A counter-example is needed only when the statement is false.
- For “all” statements, one counter-example is enough.
- Make sure the counter-example belongs to the group mentioned in the statement.

## Concept: Argument
An argument is the process of making a conclusion based on statements.

**Key Rules / Methods:**
- An argument consists of premises and a conclusion.
- A premise is a statement that gives information before making a conclusion.
- A conclusion is the outcome or decision made from the premises.
- A simple argument usually has at least two premises and one conclusion.

### Example Structure:
Premise 1: All mammals are warm-blooded.

Premise 2: Cats are mammals.

Conclusion: Cats are warm-blooded.

### Common Mistakes & Exam Tips:
- A premise is not the final answer.
- The conclusion is the result obtained from the premises.
- Check whether the conclusion follows logically from the premises.

## Concept: Specific and General Statements
Statements can be classified as specific or general.

**Key Rules / Methods:**
- A specific statement refers to a particular case.
- A general statement describes a concept, rule, or pattern.

### Examples:
| Statement | Type |
|---|---|
| The area of triangle ABC is $8$ cm$^2$. | Specific |
| All prisms have uniform cross sections. | General |
| $15$ is divisible by $3$. | Specific |
| All multiples of $2$ end with even digits. | General |
| The volume of a cube is $x^3$, where $x$ is the edge of the cube. | General |

### Common Mistakes & Exam Tips:
- “All” usually indicates a general statement.
- A named object or fixed value usually indicates a specific statement.
- A formula describing a whole concept is usually general.

## Concept: Deductive and Inductive Arguments
There are two main types of arguments: deductive arguments and inductive arguments.

**Key Rules / Methods:**
- Deductive argument:
  - Makes a specific conclusion based on general premises.
  - Moves from general to specific.
- Inductive argument:
  - Makes a general conclusion based on specific premises.
  - Moves from specific to general.

### Worked Example:
Determine whether each argument is deductive or inductive.

(a) All acute angles are less than $90^\circ$. Angle PQR is an acute angle. Thus, angle PQR is less than $90^\circ$.

This is a deductive argument because it uses a general rule to make a specific conclusion.

(b) The sum of exterior angles of a triangle is $360^\circ$. The sum of exterior angles of a quadrilateral is $360^\circ$. The sum of exterior angles of a pentagon is $360^\circ$. Thus, the sum of exterior angles of each polygon is $360^\circ$.

This is an inductive argument because it uses specific examples to make a general conclusion.

### Common Mistakes & Exam Tips:
- Deductive: general rule to specific case.
- Inductive: specific examples to general rule.
- Do not decide based only on whether the conclusion is true; look at the structure.

## Concept: Valid Deductive Argument
A deductive argument is valid if its conclusion follows logically from the premises.

**Key Rules / Methods:**
A valid deductive argument can be categorised into three forms.

### Form I:
Premise 1: All $A$ are $B$.

Premise 2: $C$ is $A$.

Conclusion: $C$ is $B$.

### Form II:
Premise 1: If $p$, then $q$.

Premise 2: $p$ is true.

Conclusion: $q$ is true.

### Form III:
Premise 1: If $p$, then $q$.

Premise 2: Not $q$ is true.

Conclusion: Not $p$ is true.

**Important:**
- Validity depends on the form of the argument.
- Validity does not depend only on whether the premises are true.
- A true premise does not always guarantee a valid argument.

### Worked Example:
Determine whether the argument is valid.

Premise 1: All multiples of $16$ are even numbers.

Premise 2: $64$ is a multiple of $16$.

Conclusion: $64$ is an even number.

This follows Form I:

Premise 1: All $A$ are $B$.

Premise 2: $C$ is $A$.

Conclusion: $C$ is $B$.

Therefore, the argument is valid.

### Worked Example:
Determine whether the argument is valid.

Premise 1: All basketballs are spherical.

Premise 2: The Earth is spherical.

Conclusion: The Earth is a basketball.

This is not valid because it has the incorrect form:

Premise 1: All $A$ are $B$.

Premise 2: $C$ is $B$.

Conclusion: $C$ is $A$.

The conclusion does not logically follow.

### Common Mistakes & Exam Tips:
- Validity is about structure.
- Do not assume an argument is valid just because the conclusion is true.
- Form III uses the contrapositive structure.

## Concept: Sound Deductive Argument
A valid deductive argument is sound if all its premises are true.

**Key Rules / Methods:**
- Valid argument: conclusion follows logically from the premises.
- Sound argument: valid argument with true premises.
- An argument can be valid but not sound.
- An argument that is not valid cannot be considered sound in the proper logical sense.

### Worked Example:
Determine whether the argument is valid and sound.

Premise 1: If $w < 9$, then $w < 19$.

Premise 2: $4 < 9$.

Conclusion: $4 < 19$.

This follows Form II:

Premise 1: If $p$, then $q$.

Premise 2: $p$ is true.

Conclusion: $q$ is true.

The argument is valid.

Both premises are true, so the argument is sound.

### Worked Example:
Determine whether the argument is valid and sound.

Premise 1: If $a \neq 0$, then $ax^n + bx + c$ is a quadratic expression.

Premise 2: $a \neq 0$.

Conclusion: $ax^n + bx + c$ is a quadratic expression.

This follows Form II, so it is valid.

However, Premise 1 is not necessarily true because $ax^n + bx + c$ is quadratic only when $n = 2$ and $a \neq 0$.

Therefore, the argument is valid but not sound.

### Common Mistakes & Exam Tips:
- Sound means valid and all premises true.
- If one premise is false, the argument is not sound.
- Always check validity first, then soundness.

## Concept: Forming a Valid Deductive Argument
A valid deductive argument can be formed by arranging the information into premises and a conclusion.

**Key Rules / Methods:**
- Identify the general rule.
- Identify the specific case.
- Write the conclusion that follows.
- Use one of the valid deductive forms.

### Worked Example:
Form a valid deductive argument.

All mammals are warm-blooded. Cats are mammals. Cats are warm-blooded.

Premise 1: All mammals are warm-blooded.

Premise 2: Cats are mammals.

Conclusion: Cats are warm-blooded.

### Worked Example:
Form a valid deductive argument.

If $x$ is greater than $0$, then $x$ has a positive value. $6$ is greater than $0$. $6$ has a positive value.

Premise 1: If $x$ is greater than $0$, then $x$ has a positive value.

Premise 2: $6$ is greater than $0$.

Conclusion: $6$ has a positive value.

### Worked Example:
Form a valid deductive argument.

If $x$ is an odd number, then $x + 1$ is divisible by $2$. $18 + 1$ is not divisible by $2$. $18$ is not an odd number.

Premise 1: If $x$ is an odd number, then $x + 1$ is divisible by $2$.

Premise 2: $18 + 1$ is not divisible by $2$.

Conclusion: $18$ is not an odd number.

### Common Mistakes & Exam Tips:
- The conclusion must match the valid argument form.
- Do not reverse the implication unless it is logically justified.
- In Form III, use “not $q$” to conclude “not $p$”.

## Concept: Strength of Inductive Arguments
An inductive argument is judged by its strength, not validity.

**Key Rules / Methods:**
- A strong inductive argument has a conclusion that is probably true if the premises are true.
- A weak inductive argument has a conclusion that is probably false or not well supported.
- The strength of an inductive argument depends on the probability that the conclusion is true.
- A greater number of premises does not automatically make an argument strong.

### Worked Example:
Determine whether the argument is strong or weak.

Premise 1: The chairs in the living room are red.

Premise 2: The chairs in the dining room are red.

Premise 3: The chairs in the study room are red.

Premise 4: The chairs in the bedroom are red.

Conclusion: All chairs in the house are red.

This argument is weak because even though the premises may be true, the conclusion is probably false. There may be other chairs in the house that are not red.

### Worked Example:
Determine whether the argument is strong or weak.

Premise 1: $11 \times 5 = 55$

Premise 2: $12 \times 5 = 60$

Conclusion: All multiples of $5$ end with digit $0$ or $5$.

This argument is strong because the conclusion is true and the examples support the known pattern.

### Common Mistakes & Exam Tips:
- Inductive arguments are about probability, not certainty.
- A conclusion from examples may still be false.
- Check whether the conclusion is well supported by the premises.

## Concept: Cogent Inductive Argument
A strong inductive argument is cogent if all its premises are true.

**Key Rules / Methods:**
- Strong and all premises true: cogent.
- Strong but at least one premise false: not cogent.
- Weak argument: not cogent.
- A weak argument is never cogent.

### Summary:
| Inductive Argument | Condition | Result |
|---|---|---|
| Strong | All premises true | Cogent |
| Strong | Some premises false | Not cogent |
| Weak | Any condition | Not cogent |

### Worked Example:
Determine whether the argument is strong or weak, and cogent or not cogent.

Premise 1: $27$ is a multiple of $3$.

Premise 2: $81$ is a multiple of $3$.

Conclusion: All multiples of $9$ are multiples of $3$.

The conclusion is true, and the premises support it.

Therefore, the argument is strong and cogent.

### Worked Example:
Determine whether the argument is strong or weak, and cogent or not cogent.

Premise 1: $1$ is a prime number.

Premise 2: $2$ is a prime number.

Premise 3: $3$ is a prime number.

Premise 4: $5$ is a prime number.

Conclusion: All prime numbers are divisible by $1$ and itself.

The conclusion is true, but Premise 1 is false because $1$ is not a prime number.

Therefore, the argument is strong but not cogent.

### Common Mistakes & Exam Tips:
- Strong does not always mean cogent.
- A cogent argument must be strong and have true premises.
- If one premise is false, the argument is not cogent.

## Concept: Forming Strong Inductive Arguments
A strong inductive argument is formed by observing specific cases, identifying a common pattern, and making a general conclusion.

**Key Rules / Methods:**
- Observe several examples or specific situations.
- Identify the common feature or pattern.
- Make a general conclusion.
- In number patterns, express the conclusion using a formula.

### Worked Example:
Form a strong inductive conclusion for the sequence:

$$
1,\ 3,\ 5,\ 7,\ldots
$$

Observe the pattern:

$$
1 = 2(0) + 1
$$

$$
3 = 2(1) + 1
$$

$$
5 = 2(2) + 1
$$

$$
7 = 2(3) + 1
$$

Therefore, the general formula is:

$$
2n + 1,\quad n = 0, 1, 2, 3, \ldots
$$

### Worked Example:
Form a strong inductive conclusion for the sequence:

$$
0,\ 9,\ 24,\ 45,\ldots
$$

Observe the pattern:

$$
0 = 3(1)^2 - 3
$$

$$
9 = 3(2)^2 - 3
$$

$$
24 = 3(3)^2 - 3
$$

$$
45 = 3(4)^2 - 3
$$

Therefore, the general formula is:

$$
3n^2 - 3,\quad n = 1, 2, 3, 4, \ldots
$$

### Common Mistakes & Exam Tips:
- Identify the starting value of $n$ correctly.
- Do not assume $n$ always starts from $1$.
- Check the formula with the first few terms.

## Concept: Solving Problems Involving Logical Reasoning
Logical reasoning problems may involve deduction, induction, formulas, and pattern recognition.

**Key Rules / Methods:**
- Use deduction when a formula or rule is already given.
- Use induction when a pattern must be observed and generalised.
- Substitute values carefully into the formula.
- Make a conclusion in the context of the problem.

### Worked Example:
The number of new cells produced after $t$ days is:

$$
P(t) = 2^t
$$

(a) How many new cells will be produced on the $8$th day?

Substitute $t = 8$:

$$
P(8) = 2^8
$$

$$
= 256
$$

Therefore, $256$ new cells will be produced on the $8$th day.

(b) On which day will the number of new cells become $2048$?

Solve:

$$
2^t = 2048
$$

Since:

$$
2048 = 2^{11}
$$

therefore:

$$
t = 11
$$

The number of new cells becomes $2048$ on the $11$th day.

### Worked Example:
The number of toy cars produced by a factory follows this pattern:

| Time | Number of Toy Cars |
|---|---:|
| 8:00 a.m. | $270$ |
| 9:00 a.m. | $520$ |
| 10:00 a.m. | $770$ |
| 11:00 a.m. | $1020$ |

Observe the pattern:

$$
270 = 250(1) + 20
$$

$$
520 = 250(2) + 20
$$

$$
770 = 250(3) + 20
$$

$$
1020 = 250(4) + 20
$$

Therefore, the general formula is:

$$
250n + 20,\quad n = 1, 2, 3, 4, \ldots
$$

If the factory operates for $15$ hours in a day:

$$
250(15) + 20 = 3750 + 20
$$

$$
= 3770
$$

Therefore, the factory produces $3770$ toy cars in a day.

### Common Mistakes & Exam Tips:
- Use deduction when the formula is given.
- Use induction when the formula must be found from a pattern.
- Always state the final conclusion clearly.
