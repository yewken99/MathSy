# Topic: Measures of Dispersion for Grouped Data
**Form:** Form 5 | **Chapter:** Chapter 7 | **Curriculum:** SPM KSSM

## Overview
This chapter focuses on grouped data and how to represent, analyse and interpret its dispersion. Students learn how to construct frequency tables, cumulative frequency tables, histograms, frequency polygons, ogives and box plots. Students also learn how to calculate range, interquartile range, variance and standard deviation for grouped data, and compare two or more data sets using suitable measures of dispersion.

## Concept: Grouped Data
Grouped data is data that has been arranged into class intervals.

**Key Rules / Methods:**
- A class interval is a range of values.
- Grouped data is useful when there are many data values.
- Instead of listing every value, data values are placed into suitable classes.
- Each class has a frequency.

### Example:
If pupils’ heights are grouped as:

| Height (cm) | Frequency |
|---|---:|
| 145 – 149 | 2 |
| 150 – 154 | 3 |
| 155 – 159 | 6 |

then the data is grouped data.

### Common Mistakes & Exam Tips:
- Grouped data does not show every original value.
- Calculations using grouped data are estimates because midpoints are used.
- Use class intervals carefully, especially when finding boundaries.

## Concept: Class Interval
A class interval is the range of values in one group of data.

### Example:
For the class interval:

$$
145 - 149
$$

the values from $145$ to $149$ are grouped together.

### Common Mistakes & Exam Tips:
- Do not confuse class interval with class size.
- The class interval is the range label, such as $145-149$.
- The class size is the width of the interval.

## Concept: Size of Class Interval
The size of class interval can be estimated using:

$$
\text{Size of class interval}
=
\frac{\text{Largest data value} - \text{Smallest data value}}{\text{Number of classes}}
$$

If the result is not a whole number, round up to a suitable whole number.

### Worked Example:
The largest height is $173$ cm and the smallest height is $145$ cm. The number of classes required is $6$.

$$
\text{Size of class interval}
=
\frac{173-145}{6}
$$

$$
=
\frac{28}{6}
$$

$$
=4.7
$$

Round up:

$$
\text{Size of class interval} \approx 5
$$

So suitable class intervals are:

$$
145-149,\ 150-154,\ 155-159,\ 160-164,\ 165-169,\ 170-174
$$

### Other Ways to Find Class Size:
For uniform class intervals, the size can also be found by:

$$
\text{Difference between consecutive lower limits}
$$

or:

$$
\text{Upper boundary} - \text{Lower boundary}
$$

### Common Mistakes & Exam Tips:
- Do not calculate class size by doing $149-145=4$ for class $145-149$.
- For continuous data, the class $145-149$ actually covers from $144.5$ to $149.5$, so the class size is $5$.
- Always use boundaries when constructing histograms.

## Concept: Lower Limit and Upper Limit
The lower limit is the smallest value in a class interval.  
The upper limit is the largest value in a class interval.

### Example:
For the class interval:

$$
150-154
$$

the lower limit is:

$$
150
$$

and the upper limit is:

$$
154
$$

### Common Mistakes & Exam Tips:
- Lower and upper limits are the visible values written in the class interval.
- Boundaries are different from limits.
- Limits are used to label classes, while boundaries are used for continuous graphs.

## Concept: Midpoint
The midpoint is the middle value of a class interval.

### Formula:
$$
\text{Midpoint}
=
\frac{\text{Lower limit}+\text{Upper limit}}{2}
$$

### Worked Example:
For the class interval:

$$
150-154
$$

the midpoint is:

$$
\frac{150+154}{2}
$$

$$
=
\frac{304}{2}
$$

$$
=152
$$

### Common Mistakes & Exam Tips:
- Midpoint is very important for calculating mean, variance and standard deviation.
- Use midpoint as the representative value of each class.
- Do not use the lower limit or upper limit as $x$ unless the question says so.

## Concept: Lower Boundary and Upper Boundary
Boundaries are used to make class intervals continuous without gaps.

### Lower Boundary Formula:
$$
\text{Lower boundary}
=
\frac{\text{Upper limit of class before it}+\text{Lower limit of current class}}{2}
$$

### Upper Boundary Formula:
$$
\text{Upper boundary}
=
\frac{\text{Upper limit of current class}+\text{Lower limit of class after it}}{2}
$$

### Example:
For the class interval:

$$
150-154
$$

the class before it is:

$$
145-149
$$

Lower boundary:

$$
\frac{149+150}{2}=149.5
$$

The class after it is:

$$
155-159
$$

Upper boundary:

$$
\frac{154+155}{2}=154.5
$$

So the actual continuous interval is:

$$
149.5-154.5
$$

### Common Mistakes & Exam Tips:
- Histograms use boundaries, not limits.
- Boundaries remove gaps between bars.
- For data measured to the nearest whole number, boundaries usually end in $.5$.
- For data measured to one decimal place, boundaries usually end in $.05$.

## Concept: Continuous Data and Discrete Data
Continuous data is data that is measured on a continuous scale.

### Examples of Continuous Data:
- Height.
- Mass.
- Time.
- Distance.
- Speed.
- Temperature.

Discrete data is data that is counted.

### Examples of Discrete Data:
- Number of pupils.
- Number of cars.
- Number of books.
- Number of families.

### Common Mistakes & Exam Tips:
- Histograms and frequency polygons are usually constructed using continuous data.
- Continuous data needs class boundaries.
- Discrete data often uses counting values.

## Concept: Frequency Table for Grouped Data
A frequency table organises grouped data into classes and shows how many values fall into each class.

### Important Columns:
| Column | Meaning |
|---|---|
| Class interval | Range of values |
| Frequency, $f$ | Number of data values in the class |
| Lower limit | Smallest value in the class |
| Upper limit | Largest value in the class |
| Midpoint, $x$ | Middle value of the class |
| Lower boundary | Actual start of class |
| Upper boundary | Actual end of class |

### Common Mistakes & Exam Tips:
- Check that all data values are included.
- Check that no class overlaps.
- Class intervals should usually have equal size.
- Total frequency should equal the total number of data values.

## Concept: Cumulative Frequency
Cumulative frequency is the running total of frequencies.

### Key Rule:
The cumulative frequency of a class is:

$$
\text{Frequency of current class}
+
\text{Total frequency of all previous classes}
$$

### Worked Example:
Given:

| Age | Frequency |
|---|---:|
| 10 – 19 | 4 |
| 20 – 29 | 5 |
| 30 – 39 | 8 |
| 40 – 49 | 7 |
| 50 – 59 | 3 |

The cumulative frequency table is:

| Age | Frequency | Cumulative Frequency |
|---|---:|---:|
| 10 – 19 | 4 | 4 |
| 20 – 29 | 5 | 9 |
| 30 – 39 | 8 | 17 |
| 40 – 49 | 7 | 24 |
| 50 – 59 | 3 | 27 |

### Common Mistakes & Exam Tips:
- Cumulative frequency should increase or stay the same.
- The final cumulative frequency must equal the total frequency.
- If the final cumulative frequency is wrong, check the addition.

## Concept: Histogram
A histogram is a graph that represents grouped continuous data using adjoining bars.

**Key Features:**
- Bars touch each other.
- The horizontal axis uses class boundaries.
- The vertical axis shows frequency.
- The height of each bar represents the frequency of that class.

### Steps to Construct a Histogram:
1. Find the lower boundary and upper boundary of each class interval.
2. Choose a suitable scale for both axes.
3. Put class boundaries on the horizontal axis.
4. Put frequency on the vertical axis.
5. Draw adjoining bars with no gaps.

### Common Mistakes & Exam Tips:
- Do not leave gaps between histogram bars.
- Use class boundaries, not class limits.
- Make sure each bar has the correct width and height.
- Histograms are suitable for continuous grouped data.

## Concept: Frequency Polygon
A frequency polygon is a graph formed by connecting the midpoints of class intervals using straight lines.

**Key Features:**
- The horizontal axis uses midpoints.
- The vertical axis uses frequencies.
- Points are plotted at the midpoint of each class.
- Adjacent points are joined using straight lines.

### Method Using a Histogram:
1. Draw the histogram first.
2. Mark the midpoint at the top of each bar.
3. Add one midpoint before the first class with frequency $0$.
4. Add one midpoint after the last class with frequency $0$.
5. Join all points using straight lines.

### Method Without a Histogram:
1. Add one class interval before the first class with frequency $0$.
2. Add one class interval after the last class with frequency $0$.
3. Find the midpoint of each class interval.
4. Plot each midpoint with its frequency.
5. Join the points using straight lines.

### Common Mistakes & Exam Tips:
- Do not join class boundaries; join midpoints.
- Add zero-frequency points at both ends.
- Frequency polygon should start and end on the horizontal axis.
- It is useful for comparing distributions.

## Concept: Distribution Shapes
Distribution shape describes the overall pattern of grouped data.

### Common Shapes:
| Shape | Description |
|---|---|
| Bell-shaped | Most data are near the centre, fewer at both ends |
| Uniform-shaped | Frequencies are almost the same across classes |
| Right-skewed | Long tail extends to the right |
| Left-skewed | Long tail extends to the left |
| Bimodal | Two peaks |
| U-shaped | Higher frequencies at both ends |
| J-shaped | Frequencies increase toward the right |
| Reverse J-shaped | Frequencies decrease toward the right |

### Common Mistakes & Exam Tips:
- Real distributions may not be perfect.
- Look at the overall pattern, not only one bar.
- A right-skewed distribution has a longer tail on the right.
- A left-skewed distribution has a longer tail on the left.

## Concept: Comparing Dispersion Using Histogram and Frequency Polygon
Dispersion means how spread out the data is.

### How to Compare:
- Wider spread means larger dispersion.
- Narrower spread means smaller dispersion.
- Data concentrated in fewer classes is less dispersed.
- Data spread across many classes is more dispersed.

### Example Interpretation:
If two swimming events are represented by histograms:
- The event with times spread from $72$ s to $102$ s has wider dispersion.
- The event with most times clustered in a smaller interval has smaller dispersion.
- For races, smaller times usually indicate better performance.

### Common Mistakes & Exam Tips:
- Better performance depends on context.
- In a race, lower time is better.
- In test marks, higher marks are better.
- Dispersion alone does not show which group performs better; consider mean, median or data position too.

## Concept: Ogive
An ogive is a cumulative frequency graph.

**Key Features:**
- The horizontal axis uses upper boundaries.
- The vertical axis uses cumulative frequency.
- Points are connected using a smooth curve.
- Ogives are useful for finding quartiles and percentiles.

### Steps to Construct an Ogive:
1. Add one class before the first class with frequency $0$.
2. Find the upper boundary for each class.
3. Find cumulative frequency for each class.
4. Choose suitable scales.
5. Plot each upper boundary against its cumulative frequency.
6. Draw a smooth increasing curve through the points.

### Common Mistakes & Exam Tips:
- Use upper boundaries, not midpoints.
- The ogive should never decrease.
- Start with a zero-frequency class before the first class.
- The last point should show the total frequency.

## Concept: Quartiles
Quartiles divide a data set into four equal parts.

### Types of Quartiles:
| Quartile | Meaning |
|---|---|
| $Q_1$ | First quartile or lower quartile |
| $Q_2$ | Second quartile or median |
| $Q_3$ | Third quartile or upper quartile |

### For Grouped Data:
Quartiles are usually estimated from an ogive.

If the total frequency is $N$:

$$
Q_1 \text{ position} = \frac{N}{4}
$$

$$
Q_2 \text{ position} = \frac{N}{2}
$$

$$
Q_3 \text{ position} = \frac{3N}{4}
$$

### Steps to Find Quartiles from an Ogive:
1. Calculate the position of $Q_1$, $Q_2$ and $Q_3$.
2. From the cumulative frequency axis, draw a horizontal line to the ogive.
3. From the intersection point, draw a vertical line down to the horizontal axis.
4. Read the corresponding data value.

### Common Mistakes & Exam Tips:
- $Q_2$ is the median.
- $Q_1$ represents the value below which about $25\%$ of data lies.
- $Q_3$ represents the value below which about $75\%$ of data lies.
- Quartile values from ogives are estimates.

## Concept: Percentile
A percentile divides a data set into $100$ equal parts.

### Notation:
Percentiles are written as:

$$
P_1,\ P_2,\ P_3,\ldots,P_{99}
$$

### Meaning:
- $P_{10}$ means the value below which about $10\%$ of the data lies.
- $P_{50}$ is the median.
- $P_{25}$ is the first quartile.
- $P_{75}$ is the third quartile.

### Percentile Position:
For a data set with total frequency $N$:

$$
P_k \text{ position}
=
\frac{k}{100} \times N
$$

### Worked Example:
If $N=50$, then the position of $P_{10}$ is:

$$
\frac{10}{100}\times 50
$$

$$
=5
$$

So $P_{10}$ is found at cumulative frequency $5$ on the ogive.

### Common Mistakes & Exam Tips:
- Percentile position is not always the percentile value.
- First find the position, then read the value from the ogive.
- $P_{50}$ and $Q_2$ are the same.

## Concept: Range for Grouped Data
Range measures the spread from the lowest class to the highest class.

### Formula:
$$
\text{Range}
=
\text{Midpoint of highest class}
-
\text{Midpoint of lowest class}
$$

### Worked Example:
If the lowest class is $400-499$ and the highest class is $900-999$:

Midpoint of lowest class:

$$
\frac{400+499}{2}=449.5
$$

Midpoint of highest class:

$$
\frac{900+999}{2}=949.5
$$

Range:

$$
949.5-449.5=500
$$

### Common Mistakes & Exam Tips:
- For grouped data, use midpoints of the highest and lowest classes.
- Do not simply subtract the lowest boundary from the highest boundary unless instructed.
- Range is affected by extreme values.

## Concept: Interquartile Range
Interquartile range, or IQR, measures the spread of the middle $50\%$ of the data.

### Formula:
$$
\text{Interquartile range}
=
Q_3-Q_1
$$

### Worked Example:
If:

$$
Q_1=614.5
$$

and:

$$
Q_3=809.5
$$

then:

$$
\text{IQR}=809.5-614.5
$$

$$
=195
$$

### Meaning:
An interquartile range of $195$ g means the middle $50\%$ of the data has a spread of $195$ g.

### Common Mistakes & Exam Tips:
- Find $Q_1$ and $Q_3$ first.
- For grouped data, $Q_1$ and $Q_3$ are often estimated from an ogive.
- IQR is less affected by extreme values than range.

## Concept: Mean for Grouped Data
The mean for grouped data is calculated using midpoints.

### Formula:
$$
\bar{x}
=
\frac{\sum fx}{\sum f}
$$

where:
- $f$ is frequency.
- $x$ is midpoint.
- $fx$ is frequency multiplied by midpoint.

### Steps:
1. Find the midpoint $x$ for each class.
2. Calculate $fx$ for each class.
3. Find $\sum fx$.
4. Find $\sum f$.
5. Use the formula.

### Common Mistakes & Exam Tips:
- Use midpoint, not class limit.
- Make sure all $fx$ values are added correctly.
- The mean is an estimate because grouped data uses midpoints.

## Concept: Variance for Grouped Data
Variance measures how spread out the data is from the mean.

### Formula:
$$
\sigma^2
=
\frac{\sum fx^2}{\sum f}
-
\bar{x}^2
$$

where:
- $x$ is midpoint.
- $f$ is frequency.
- $\bar{x}$ is mean.
- $\sum fx^2$ means the sum of $f \times x^2$.

### Steps:
1. Find the midpoint $x$ for each class.
2. Calculate $fx$.
3. Calculate $x^2$.
4. Calculate $fx^2$.
5. Find $\sum f$, $\sum fx$ and $\sum fx^2$.
6. Find the mean.
7. Substitute into the variance formula.

### Common Mistakes & Exam Tips:
- $fx^2$ means $f \times x^2$, not $(fx)^2$.
- Variance has squared units.
- Round according to the question instruction.
- Keep enough decimal places during calculation.

## Concept: Standard Deviation for Grouped Data
Standard deviation is the square root of variance.

### Formula:
$$
\sigma
=
\sqrt{
\frac{\sum fx^2}{\sum f}
-
\bar{x}^2
}
$$

### Meaning:
- A smaller standard deviation means the data is more consistent.
- A larger standard deviation means the data is more spread out.
- Standard deviation has the same unit as the original data.

### Worked Example Summary:
For grouped water usage data:

$$
\sum f = 95
$$

$$
\sum fx = 17417.5
$$

$$
\sum fx^2 = 3215133.75
$$

Mean:

$$
\bar{x}=
\frac{17417.5}{95}
$$

$$
=183.34
$$

Variance:

$$
\sigma^2
=
\frac{3215133.75}{95}
-
\left(\frac{17417.5}{95}\right)^2
$$

$$
=229.1856
$$

Standard deviation:

$$
\sigma=\sqrt{229.1856}
$$

$$
=15.1389
$$

### Common Mistakes & Exam Tips:
- Standard deviation is not the same as variance.
- Standard deviation is the square root of variance.
- If comparing consistency, choose the data set with the smaller standard deviation.
- If comparing size or level, also compare mean.

## Concept: Box Plot
A box plot displays data using the five-number summary.

### Five-Number Summary:
| Value | Meaning |
|---|---|
| Minimum | Smallest value |
| $Q_1$ | First quartile |
| $Q_2$ | Median |
| $Q_3$ | Third quartile |
| Maximum | Largest value |

### Box Plot Structure:
- The box starts at $Q_1$ and ends at $Q_3$.
- A line inside the box marks the median $Q_2$.
- The left whisker extends from the minimum to $Q_1$.
- The right whisker extends from $Q_3$ to the maximum.

### Common Mistakes & Exam Tips:
- The box represents the middle $50\%$ of the data.
- The whiskers represent the lower and upper parts of the data.
- A box plot can show skewness.

## Concept: Constructing a Box Plot from an Ogive
To construct a box plot from an ogive:

1. Read the minimum value from the graph.
2. Read the maximum value from the graph.
3. Find $Q_1$, $Q_2$ and $Q_3$ from the ogive.
4. Draw a number line.
5. Mark minimum, $Q_1$, $Q_2$, $Q_3$ and maximum.
6. Draw the box and whiskers.

### Worked Example:
From an ogive of $90$ starfruits:

$$
\text{Minimum}=80
$$

$$
\text{Maximum}=150
$$

$$
Q_1=116
$$

$$
Q_2=123
$$

$$
Q_3=128
$$

These values are used to construct the box plot.

### Common Mistakes & Exam Tips:
- Use five values only.
- Do not use class intervals directly in the box plot.
- Quartile values from ogives are estimates.

## Concept: Interpreting Box Plot Shape
The shape of a box plot can show the distribution.

### Symmetric Distribution:
- Median is near the middle of the box.
- Left and right whiskers are about the same length.

### Left-Skewed Distribution:
- Left side of the box or left whisker is longer.
- The tail extends more to the left.

### Right-Skewed Distribution:
- Right side of the box or right whisker is longer.
- The tail extends more to the right.

### Common Mistakes & Exam Tips:
- Do not look only at the median.
- Compare both sides of the box and the whiskers.
- A longer left side indicates left-skewed.
- A longer right side indicates right-skewed.

## Concept: Comparing Two Data Sets Using Mean and Standard Deviation
Mean and standard deviation are useful for comparing grouped data.

### How to Compare:
| Measure | Meaning |
|---|---|
| Larger mean | Higher average value |
| Smaller mean | Lower average value |
| Larger standard deviation | Less consistent / more spread out |
| Smaller standard deviation | More consistent / less spread out |

### Example Interpretation:
If Hybrid A has:

$$
\bar{x}=14.35
$$

and:

$$
\sigma=0.64
$$

while Hybrid B has:

$$
\bar{x}=14.10
$$

and:

$$
\sigma=0.70
$$

then Hybrid A produces larger and more consistent petals because:
- It has a larger mean.
- It has a smaller standard deviation.

### Common Mistakes & Exam Tips:
- Do not use standard deviation alone if the question asks which is larger or better.
- Use mean to compare average level.
- Use standard deviation to compare consistency.
- A smaller standard deviation means values are closer to the mean.

## Concept: Solving Problems from an Ogive
Sometimes an ogive is given, and you need to form a frequency table.

### Method:
1. Read cumulative frequency at each upper boundary.
2. Subtract consecutive cumulative frequencies to get class frequencies.
3. Use the class intervals given in the question.
4. Use the frequency table to calculate mean and standard deviation.

### Example:
If cumulative frequencies are:

$$
6,\ 22,\ 54,\ 70,\ 80
$$

then class frequencies are:

$$
6-0=6
$$

$$
22-6=16
$$

$$
54-22=32
$$

$$
70-54=16
$$

$$
80-70=10
$$

### Common Mistakes & Exam Tips:
- Frequency is found by subtracting cumulative frequencies.
- The first frequency is first cumulative frequency minus $0$.
- Always check that the total frequency matches the final cumulative frequency.

## Concept: Cumulative Histogram
A cumulative histogram is similar to a histogram, but the vertical axis uses cumulative frequency.

### Key Rules:
- Horizontal axis uses class boundaries.
- Vertical axis uses cumulative frequency.
- The bars increase from left to right.
- An ogive can be drawn from the cumulative histogram.

### Common Mistakes & Exam Tips:
- Do not confuse normal frequency with cumulative frequency.
- A cumulative histogram should not decrease.
- It is linked closely to the construction of an ogive.

## Concept: Statistical Investigation Mini Project
A statistical investigation involves collecting, organising, representing, analysing and interpreting data.

### Main Steps:
1. Plan the investigation.
2. Collect data.
3. Organise data into frequency tables.
4. Represent data using graphs.
5. Calculate measures of central tendency and dispersion.
6. Interpret the results.
7. Make conclusions and suggestions.

### Example: BMI Investigation
Students may collect:
- Gender.
- Height.
- Mass.
- Hours of sports activity.

BMI is calculated by:

$$
\text{BMI}
=
\frac{\text{Mass (kg)}}{\text{Height (m)} \times \text{Height (m)}}
$$

Then pupils can be classified as:
- Underweight.
- Normal.
- Overweight.
- Obese.

### Common Mistakes & Exam Tips:
- Choose respondents randomly where possible.
- Use suitable class intervals.
- Use suitable graphs for the data type.
- Interpret findings clearly instead of only showing calculations.

## Common Mistakes & Exam Tips for the Whole Chapter
- Use boundaries for histograms and ogives.
- Use midpoints for mean, variance and standard deviation.
- Do not confuse frequency with cumulative frequency.
- Do not calculate $fx^2$ as $(fx)^2$.
- Histogram bars must touch.
- Frequency polygon uses midpoints.
- Ogive uses upper boundaries and cumulative frequency.
- Quartiles and percentiles from ogives are estimates.
- Smaller standard deviation means more consistent data.
- Larger mean does not always mean better; interpret according to the context.
- Box plots use minimum, $Q_1$, median, $Q_3$ and maximum.
- For grouped data, many answers are approximate because the original data values are not fully known.
