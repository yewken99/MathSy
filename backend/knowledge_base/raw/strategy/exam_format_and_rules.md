## 2. Official Exam Overview

SPM Mathematics uses two written examination papers:

| Paper | Code | Main Format |
|---|---|---|
| Kertas 1 | 1449/1 | Objective multiple-choice paper |
| Kertas 2 | 1449/2 | Subjective structured paper |

Both papers assess Mathematics content from the KSSM syllabus, covering Tingkatan 1 until Tingkatan 5.

---

# 3. Kertas 1: Mathematics Paper 1

## Basic Format

| Item | Details |
|---|---|
| Paper code | 1449/1 |
| Type of instrument | Written examination |
| Type of item | Objective multiple-choice |
| Number of questions | 40 questions |
| Total marks | 40 marks |
| Answer requirement | Answer all questions |
| Duration | 1 hour 30 minutes |
| Scoring method | Dichotomous |
| Additional tool | Non-programmable scientific calculator |

## Meaning of Kertas 1 Format

Kertas 1 consists of objective multiple-choice questions.

Each question normally has:
- one final answer,
- answer options such as A, B, C and D,
- no need for written working in the actual exam answer sheet.

## Kertas 1 Scoring Rule

Kertas 1 uses dichotomous scoring.

This means:
- correct answer = full mark,
- wrong answer = no mark,
- no partial marks are awarded.

## Kertas 1 Constructs Assessed

Kertas 1 assesses:
- Remembering and Understanding,
- Applying,
- Analysing.

# 4. Kertas 2: Mathematics Paper 2

## Basic Format

| Item | Details |
|---|---|
| Paper code | 1449/2 |
| Type of instrument | Written examination |
| Type of item | Subjective restricted response and structured response |
| Total marks | 100 marks |
| Duration | 2 hours 30 minutes |
| Scoring method | Analytic |
| Additional tools | Non-programmable scientific calculator and geometry tools |

## Section Breakdown

| Section | Number of Questions | Marks | Answer Requirement |
|---|---:|---:|---|
| Bahagian A | 10 questions | 40 marks | Answer all questions |
| Bahagian B | 5 questions | 45 marks | Answer all questions |
| Bahagian C | 2 questions | 15 marks | Answer one question |

## Meaning of Kertas 2 Format

Kertas 2 consists of subjective and structured questions.

Questions may require students to:
- show working,
- draw graphs,
- complete tables,
- justify answers,
- solve multi-step problems,
- interpret diagrams,
- use formulas,
- make decisions based on calculations.

## Kertas 2 Scoring Rule

Kertas 2 uses analytic scoring.

This means marks can be awarded for:
- correct method,
- correct substitution,
- correct intermediate step,
- correct final answer,
- correct unit,
- correct reasoning or justification,
- correct graph/diagram construction.

## Kertas 2 Constructs Assessed

Kertas 2 assesses:
- Remembering and Understanding,
- Applying,
- Analysing,
- Evaluating,
- Creating.

This means Kertas 2 can include more complex questions than Kertas 1, including questions that require judgement, justification, modelling, or explanation.

# 6. Important Exam Rules for Students

## Before Answering

Students should:
- read the full question,
- check whether it is Kertas 1 or Kertas 2 style,
- identify what topic is being tested,
- identify the required unit,
- check whether all questions must be answered.

## During Calculation

Students should:
- show working for Kertas 2,
- use formulas correctly,
- keep enough decimal places during calculation,
- round only when appropriate,
- use correct units.

## For Graph Questions

Students should:
- label axes,
- use suitable scale,
- plot points accurately,
- join points as required,
- read values carefully from the graph.

## For Geometry Questions

Students should:
- use ruler/protractor/compass when needed,
- label points clearly,
- state transformation fully,
- include centre, angle, direction, scale factor or mirror line where required.

## For Justification Questions

Students should:
- do not only write “yes” or “no”,
- support the answer with calculation or reasoning,
- compare values clearly,
- conclude in context.
